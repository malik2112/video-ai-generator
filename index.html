Token Hugging Face (gratis, disarankan)

Tanpa token, generate memakai kuota GPU gratis ZeroGPU yang dipakai bersama semua pengunjung — kadang langsung jalan, kadang kuotanya sedang habis. Dengan token gratis dari huggingface.co/settings/tokens (buat token tipe Read), kuotanya jadi kuota akunmu sendiri yang jauh lebih lega. Token hanya dipakai selama halaman ini terbuka dan hanya dikirim ke Hugging Face — tidak disimpan di server mana pun.
